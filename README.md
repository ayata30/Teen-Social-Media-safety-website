# Teen Social Media safety website

An interactive event website that allows users to RSVP to a social media safety event. Designed to raise awareness about the importance of safe online habits for teens.
⚠️ Note: This project was originally developed using VSCode for Education, which is why the Git commit history begins more recently.

 ## Features
✅ Fully functional RSVP form

✅ Responsive modal for confirmation

✅ Clean, user-friendly layout

## How to Run
Clone the repo:
git clone https://github.com/yourusername/teen-social-media-safety.git
Open index.html in any modern browser.


No installation or build tools required. It's a simple, self-contained site.
